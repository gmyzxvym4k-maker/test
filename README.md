# 📄 Word & OpenClaw 智能文档协作平台

一个纯前端、本地化、高保真、AI 驱动的智能文档校对与批注协作工具。

## 📋 文档概述

| 项目 | 说明 |
|:---|:---|
| **版本** | V1.0 |
| **部署模式** | 纯前端静态部署（无需 Docker/后端） |
| **核心定位** | 本地化、高保真、AI 驱动的智能文档校对与批注协作工具 |

## 🎯 产品定位与核心目标

1. **高保真文档处理**：实现 `.docx` 文件上传/粘贴时 `100%` 还原原始排版、字体、颜色、表格及修订痕迹
2. **精准 AI 批注**：通过对接用户自定义的大模型 API，实现智能文本审核，并在**原文精确位置**生成可视化批注
3. **沉浸式交互体验**：批注与原文通过虚线锚定，滚动同步、智能防重叠；支持直接在批注框内编辑，零弹窗干扰
4. **开箱即用**：纯静态架构，支持任意本地 HTTP 服务运行，全按钮功能完整，数据本地安全存储

## ✨ 功能特性

### 整体布局
- **左侧：Word 编辑区** - 类 Word 排版视图（A4 比例白底 + 阴影），顶部工具栏，底部状态栏
- **右侧：批注轨道** - 独立固定宽度区域，承载与原文水平对齐的批注卡片，通过 SVG 虚线与原文锚点连接
- **右侧：OpenClaw 对话区** - 深色顶栏 + 消息流布局，支持历史对话滚动、快捷指令按钮、流式/阻塞式 AI 响应展示

### 文档编辑与格式还原
- 📝 **富文本工具栏** - 加粗、斜体、下划线、删除线、字号切换、字体颜色、无序/有序列表
- 📤 **Word 导入** - 支持 `Ctrl+V` 粘贴（保留 100% 原生样式）或上传 `.docx` 文件（基于 mammoth.js 解析）
- 📊 **实时状态显示** - 字数统计、批注数量、API 连接状态、自动保存时间戳
- 👁️ **修订视图切换** - 一键切换批注高亮的显隐状态

### AI 智能审核与批注生成
- ⚙️ **API 配置中心** - 配置 API 地址、API Key、模型名称，支持测试连接验证
- 🎯 **指令解析** - 支持自然语言输入或快捷按钮：`检查文本错误 `、` 优化表达 `、` 检查逻辑 `、` 格式规范 `、` 总结要点`
- 📦 **JSON 结构化响应** - 强制 AI 返回标准 JSON 格式：`{ quote: "原文片段", type: "错误类型", suggestion: "修改建议" }`
- 🎯 **精准定位** - 前端通过 `TreeWalker` 遍历 DOM 精准匹配文本节点，自动包裹高亮标签并生成批注卡片

### 批注交互系统（核心）
- 📌 **水平锚定** - 批注卡片 Y 轴坐标严格等于被批注文本块的 Y 轴坐标，滚动时实时重算保持对齐
- 🔗 **虚线连接** - SVG 绘制蓝色虚线（`stroke-dasharray: 6,4`），起点为原文右侧，终点为批注框左侧圆点
- 🧠 **智能防重叠** - 贪心算法排序，自动下推至安全间距（`gap: 16px`）
- ✏️ **内联编辑** - 批注内容区 `contenteditable="true"`，失焦自动保存，**无弹窗**
- 🗑️ **删除管理** - 悬停显示删除按钮，同步移除批注卡片、SVG 连线、原文高亮标签和内存数据

### 导出与下载
- 📄 **导出 HTML** - 打包当前内容 + 基础样式，生成独立可预览的静态页面
- 💾 **下载 .docx** - 使用 docx.js 库映射为原生批注对象，确保在 Microsoft Word/WPS 中批注、高亮、排版完整保留

## 🛠️ 技术栈

| 模块 | 技术选型 |
|:---|:---|
| **UI/样式** | 原生 CSS3 + CSS Variables（Flex/Grid 布局，毛玻璃效果，自定义滚动条） |
| **文档解析** | mammoth.js（样式映射表还原标题/加粗/斜体/表格/图片） |
| **文档生成** | docx.js + file-saver（DOM → OOXML 映射，原生批注注入） |
| **批注引擎** | DOM API + SVG + ResizeObserver（TreeWalker 定位，坐标计算，监听重排） |
| **状态管理** | SafeStorage 封装（自动检测 localStorage，沙箱环境降级至内存） |

## 🚀 快速开始

### 部署方式（任选其一）

```bash
# 方式 1：双击直接打开（部分浏览器可能限制跨域）
# 直接双击 index.html

# 方式 2：Python 内置服务（推荐）
python -m http.server 8080
# 访问 http://localhost:8080

# 方式 3：Node.js 服务
npx serve .

# 方式 4：部署到静态托管
# Vercel / GitHub Pages / Cloudflare Pages / Nginx / Apache
```

### 使用流程

1. 打开应用后，点击「⚙️ 设置」配置您的 AI API（兼容所有 OpenAI 格式接口）
2. 通过 `Ctrl+V` 粘贴 Word 内容或点击「📤 上传」导入 `.docx` 文件
3. 在右侧对话区输入指令（如"检查文本错误"）或点击快捷按钮
4. 查看 AI 生成的精准批注，可直接在批注框内编辑修改
5. 完成后点击「💾 下载」导出带批注的 Word 文档

## 🔒 安全性

- 🛡️ **本地化处理**：文档内容**不经过第三方服务器**，仅发送至用户自行配置的 API 端点
- 🔐 **安全存储**：API Key 采用 `SafeStorage` 机制，自动降级内存存储，兼容浏览器沙箱/iframe 环境
- 🚫 **零数据上传**：所有数据处理均在本地浏览器完成
